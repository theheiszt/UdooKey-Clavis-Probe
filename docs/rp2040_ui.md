## 1. Overview & Architectural Philosophy

The UDOO KEY firmware integrates an on-device local front panel consisting of a **color ST7735 TFT display (SPI0)** and a **5-way tactile button navigation matrix**.

This front panel operates as an autonomous, standalone instrument interface:
- **Zero Host Dependency**: The instrument can be operated, monitored, and configured in the field without a connected PC or smartphone.
- **Timing Decoupling**: Display updates are decoupled from the timing-critical PIO0/DMA sampling engine. Refresh routines are throttled during active acquisitions to prevent DMA ring buffer starvation or jitter.
- **Dynamic Bus Arbitration**: The hardware `SPI0` peripheral is intelligently shared between the onboard display (`GP18..GP20`) and the external probe bus (`GP2..GP5`). When probe SPI mode is entered, the display bus is safely released and updates paused until the tool exits back to Hi-Z.
- **Mirroring & CLI Injection**: Every button press and screen state can be simulated remotely via the USB CDC terminal (`btn up/down/left/right/select` and `disp` commands).

## 2. Hardware Wiring & Electrical Specifications

### 2.1 ST7735 Color TFT Display (SPI0)
The display is wired to dedicated RP2040 GPIO pins:

| Display Signal | RP2040 GPIO | Raspberry Pi Pico Pin | UDOO KEY Header | Electrical Notes |
| :--- | :---: | :---: | :--- | :--- |
| **SCK / SCL** | **GP18** | Pin 24 | Header P1 Pin 17 | Hardware SPI0 clock, 4mA drive, 8 MHz default |
| **MOSI / SDA** | **GP19** | Pin 25 | Header P1 Pin 16 | Hardware SPI0 data out (TX), 4mA drive |
| **MISO** | **GP20** | Pin 26 | Header P1 Pin 15 | Hardware SPI0 data in (RX) / Shared with Buzzer |
| **CS** | **GP13** | Pin 17 | Header P2 Pin 17 | Active-LOW SIO digital output; idle HIGH |
| **DC / A0** | **GP12** | Pin 16 | Header P2 Pin 16 | Data (HIGH) / Command (LOW) selector |
| **RST** | **GP11** | Pin 15 | Header P2 Pin 15 | Active-LOW hardware reset pulse (25ms low, 120ms wait) |
| **VCC** | — | Pin 36 or 40 | Header P2 Pin 16 or 20 | 3.3V or 5V (see Section 6 for LDO notes) |
| **GND** | — | Pin 18 / 23 | Header P1 Pin 18 / P2 Pin 3 | System ground reference |
| **BLK / LED** | — | Pin 36 | Header P2 Pin 16 | Backlight anode (connected to 3.3V) |

### 2.2 Five-Way Tactile Button Navigation Matrix
Buttons use internal pull-ups (`INPUT_PULLUP`) and switch directly to GND:

| Button | RP2040 Pin | Pico Pin | UDOO KEY Header | Default Function |
| :--- | :---: | :---: | :--- | :--- |
| **UP** | **GP15** | Pin 20 | Header P1 Pin 20 | Move selection up / Increase sample rate / Previous |
| **DOWN** | **GP16** | Pin 21 | Header P2 Pin 1 | Move selection down / Decrease sample rate / Next |
| **LEFT** | **GP17** | Pin 22 | Header P2 Pin 2 | Back / Return to Main Menu / Cancel |
| **RIGHT** | **GP21** | Pin 27 | Header P2 Pin 7 | Enter submenu / Advance / Cycle trigger pos (0%..90%) |
| **SELECT** | **GP22** | Pin 29 | Header P2 Pin 9 | Arm / Stop Capture / Execute tool / Confirm |

- **Debounce Filter**: 20 ms software debounce window on state transitions.
- **Auto-Repeat**: Holding a directional button triggers continuous stepping after 500 ms delay at a 150 ms repeat interval.

### 3.1 Screen 1: Logic Analyzer (`UIScreen::LOGIC_ANALYZER`)
- **Header**: Displays current mode, sample rate, trigger mode tag (`[A]`, `[R]`, `[F]`, `[Q]`, `[P]`, `[E]`), prescaler division (`x1`, `x2`, `x4`), and acquisition state (`READY`, `RUNNING`, `SIGROK`).
- **Waveform Area**: 8 parallel horizontal channels (`CH0` to `CH7`), each rendered in an unambiguous high-contrast trace color:
  - CH0: Bright Green (`0x07E0`)
  - CH1: Cyan (`0x07FF`)
  - CH2: Yellow (`0xFFE0`)
  - CH3: Orange (`0xFD20`)
  - CH4: Magenta (`0xF81F`)
  - CH5: Purple (`0x9E3F`)
  - CH6: Light Blue (`0x041F`)
  - CH7: White (`0xFFFF`)
- **Trigger Line**: Vertical red dashed cursor with a top **`T`** marker indicating the exact sample index corresponding to `pre_trigger_pct` (0%, 25%, 50%, 75%, 90%).
- **Navigation Controls**:
  - `SELECT`: Toggle Arm / Stop Capture.
  - `UP`: Increase sample rate (100k -> 1M -> 5M -> 10M -> 25M -> 50M -> 100M).
  - `DOWN`: Decrease sample rate.
  - `RIGHT`: Cycle pre-trigger position ratio (0% -> 25% -> 50% -> 75% -> 90%).
  - `LEFT`: Return to Main Menu.

### 3.2 Screen 2: Measurements (`UIScreen::MEASUREMENTS`)
Provides real-time multi-channel analog and precision digital measurements:
- **3-Channel ADC Voltmeter**:
  - `ADC0 (GP26)`: Calibrated voltage (0.000 to 3.300 V, 16x oversampled).
  - `ADC1 (GP27)`: Calibrated voltage.
  - `ADC2 (GP28)`: Calibrated voltage.
  - `VSYS / TEMP`: Power rail voltage and RP2040 silicon temperature.
- **Selectable Digital Measurement Probe**:
  - Pin selector cycles across `GP10 (EXT TRIG)` and probe bus `GP2` through `GP9`.
  - **Frequency**: Hardware slice accumulation (e.g. `10.000 MHz`, `25.40 kHz`).
  - **Period**: Exact reciprocal period (e.g. `100.0 ns`, `39.37 us`).
  - **Pulse Width**: High-state pulse duration (e.g. `50.0 ns`).
  - **Duty Cycle**: High-state ratio percentage (e.g. `50.0 %`).
- **Hardware Prescaler & Protection**: Reports active division ratio (GP14 `x1`, `x2`, `x4`) and protection relay state (`ON` / `OFF`).
- **Navigation Controls**:
  - `UP` / `DOWN`: Cycle active digital measurement probe pin (`GP10`, `GP2`..`GP9`).
  - `SELECT`: Force instantaneous reading refresh.
  - `LEFT`: Return to Main Menu.

### 3.3 Screen 3: Continuity Test (`UIScreen::CONTINUITY`)
- **Visual Display**: Large banner displaying `CONNECTED` (bright green) or `OPEN CIRCT` (dark red).
- **Resistance Readout**: Calibrated bridge calculation across ADC0 (`GP26`), ranging from `< 0.1 Ω` up to `> 1 MΩ`.
- **Acoustic Beeper**: Generates an audible tone on `GP20` buzzer when measured resistance falls below the configured threshold.
- **Navigation Controls**:
  - `UP`: Increase resistance threshold (10Ω -> 25Ω -> 50Ω -> 100Ω).
  - `DOWN`: Decrease resistance threshold (100Ω -> 50Ω -> 25Ω -> 10Ω).
  - `SELECT`: Mute / Unmute acoustic buzzer.
  - `LEFT`: Return to Main Menu (automatically mutes buzzer on exit).

---

### 3.4 Screen 4: Analog Scope (`UIScreen::ANALOG_SCOPE`)
- **Display**: Real-time 50 kSPS 128-sample oscilloscope waveform trace on ADC0 (`GP26`).
- **Graticule**: 28x16 pixel graticule grid with software rising-edge trigger at 1.65 V.
- **Readout**: Peak-to-peak voltage (`Vpp`), average voltage (`Vavg`), estimated signal frequency, and trigger lock indicator (`[TRG] LOCKED` / `FREE`).
- **Navigation Controls**:
  - `SELECT`: Refresh / pause live trace.
  - `LEFT`: Return to Main Menu.

---

### 3.5 Screen 5: Protocol Tools (`UIScreen::PROTOCOL_TOOLS`)
Direct front panel access to Bus Pirate protocol engines:
1. **I2C Bus Scan**: Probes 7-bit addresses `0x08..0x77` on `GP4(SDA)` / `GP5(SCL)`.
2. **SPI Flash Info**: Dynamic bus handoff, reads 3-byte JEDEC manufacturer ID (0x9F).
3. **UART Bridge**: Activates 115200 baud transceiver bridge on `GP4(TX)` / `GP5(RX)`.
4. **1-Wire Search**: Scans for Dallas / Maxim 64-bit ROM IDs on `GP6(DQ)`.
5. **Digital I/O (DIO)**: Enters live multi-channel GPIO probe state monitor.
6. **USB Bus Prober**: Evaluates physical line states on `GP2(D+)` and `GP3(D-)` (SE0, SE1, J, K, and 1.5M/12M bus speed).
7. **ARM SWD [UNVERIF]**: Software SWD target interrogator (marked as hardware test pending).
8. **Safe Hi-Z Mode**: Tri-states all probe pins to prevent bus contention.
- **Navigation Controls**:
  - `UP` / `DOWN`: Scroll tool list (windowed 6-row view with scroll arrows).
  - `SELECT` / `RIGHT`: Execute selected tool and display toast notification.
  - `LEFT`: Return to Main Menu.

### 3.6 Screen 6: Wireless & ESP32 (`UIScreen::WIRELESS_ESP32`)
Exposes all verified dual-MCU and ESP32 wireless subsystems:
- **Inter-MCU Link**: Status of the 1 Mbps factory UART link (`GP0/GP1` ◄► `IO22/IO19`).
- **Packet Counters**: Live `TX` and `RX` CRC-16 packet transmission metrics.
- **SoftAP Status**: SSID (`UDOO-BIT-PIRATE-SCOPE`), Gateway IP (`192.168.4.1`), Channel 1, and web server ports (HTTP `80`, WebSocket `81`).
- **Telemetry Engines**: Reports operational status of the ESP32 BLE advertisement scanner and 802.11 promiscuous PCAP sniffer.
- **Navigation Controls**:
  - `SELECT`: Transmit keepalive ping packet to ESP32 coprocessor.
  - `LEFT`: Return to Main Menu.

### 3.8 Screen 8: Settings & Diagnostics (`UIScreen::SETTINGS`)
1. **Trig Mode**: Cycles trigger engine (Auto -> Rise -> Fall -> Qual -> Pattern).
2. **Prescale**: Cycles GP14 prescaler flip-flop (x1 -> x2 -> x4).
3. **Protect**: Toggles front-end overvoltage protection relay/FET (ON / OFF).
4. **Rotate**: Cycles display orientation (0=Portrait, 1=Landscape, 2=Inverted Portrait, 3=Inverted Landscape).
5. **Hardware Diag**: Enters live pin-level diagnostics screen (`UIScreen::DIAGNOSTICS`).
6. **Display Test**: Executes direct RGBW color bar test pattern (`ui_run_display_test()`).
7. **Self Test 17/17**: Executes comprehensive 17-point hardware self-test suite.
8. **System Info**: Displays RP2040 PLL clocks (133 MHz), 264 KB SRAM, 16 MB QSPI Flash, and firmware build date (`UIScreen::SYS_INFO`).

## 5. CLI Remote Simulation & Diagnostic Commands

All front panel features can be tested and operated remotely via the USB CDC serial terminal:

### 5.1 Button Simulation Bridge
```text
btn up        (or btn u)   - Simulate UP button press
btn down      (or btn d)   - Simulate DOWN button press
btn left      (or btn l)   - Simulate LEFT button press (Back)
btn right     (or btn r)   - Simulate RIGHT button press (Enter/Advance)
btn select    (or btn s)   - Simulate SELECT button press
```

### 5.2 Display Driver Commands
```text
disp                       - Query current tab, SPI speed, rotation, inversion, and VCOM
disp test                  - Draw full-screen Red, Green, Blue, White diagnostic test bars
disp test init             - Assert 25ms hardware reset pulse and re-execute initR()
disp tab 144green          - Select 1.44" ST7735S square profile (128x128, default production)
disp tab black             - Select ST7735B/S Black-Tab diagnostic profile
disp tab red               - Select ST7735R Red-Tab diagnostic profile
disp speed 8000000         - Set display SPI clock to 8 MHz (safe for jumper wires)
disp speed 16000000        - Set display SPI clock to 16 MHz
disp inv                   - Toggle display color inversion (INVON / INVOFF)
disp vcom 0x2C             - Adjust ST7735 VCOM contrast voltage register
disp rot <0-3>             - Set screen rotation (0=0°, 1=90°, 2=180°, 3=270°)
```

## 6. Troubleshooting Display Contrast & Panel Variations

### 6.1 Washed-Out Contrast / Low Brightness
1. **Module LDO Starvation**: Breakout boards with an onboard 3.3V regulator (such as 662K) must be powered from the **5V rail (`VBUS`, Header P2 Pin 20)** rather than 3.3V. Powering an LDO from 3.3V produces ~2.8V, starving the ST7735 charge pump.
2. **Color Inversion**: If colors appear inverted (black looks white), run `disp inv` or call `ui_toggle_invert()`.
3. **VCOM Voltage**: Liquid crystal bias can be optimized by setting VCOM: `disp vcom 0x2C` or `disp vcom 0x38`.

### 6.2 Pixel Offset or Shifted Edges
- The installed 1.44" 128x128 display uses `INITR_144GREENTAB` which applies the required 2-pixel hardware column/row offset.
- The UI geometry is strictly locked to 128x128 pixels (`DISPLAY_WIDTH = 128`, `DISPLAY_HEIGHT = 128`).
